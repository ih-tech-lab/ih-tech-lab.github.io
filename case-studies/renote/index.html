re:note, a Chrome side-panel notepad that keeps notes on the device, next to the page

re:note is IH-Tech’s own Chrome extension. It opens a notepad in the browser’s side panel and attaches each note to the page it was written on.

Challenge

Notes that stay with the page they describe

Notes about a web page usually live somewhere else: another app, a document, a bookmark folder. re:note keeps them in Chrome’s side panel, attached to the page, and brings them back on the next visit.

Two constraints shaped the build: the extension installs without access to the sites a person visits, and notes stay on that person’s device.

Engagement

Six parts of the build

  1. Notes attached to pages

    “This Page” shows the notes for the open page and “All Notes” shows everything, with a rich text editor, to-do lists, color-coded stacks, search, and filters.

  2. Reminders and capture

    Reminders fire Chrome notifications. Keyboard shortcuts open the panel and start a note. Highlights, image pins, and right-click capture come with the optional annotations mode.

  3. Installs without site access

    Version 1.0 asks for no access to visited sites at install. Access is requested only when a person turns on annotations, and the content scripts are registered at that moment.

  4. Notes stay on the device

    Notes live in the browser’s IndexedDB. There is no account, no sync, and no server. A PIN lock and CSV export are built in. Anonymous usage analytics are on by default and can be turned off in Settings.

  5. Built for the store review

    Analytics were rebuilt without remote code to meet the Chrome Web Store’s Manifest V3 rules, and a release script prepares every store listing field.

  6. A site that explains it

    getrenote.com is a static Next.js site with 17 use-case pages and 7 comparisons with other note tools.

How a note moves through re:note

  1. Open the side panel on any page
  2. Write a note, a to-do, or a reminder
  3. The note is saved on the device
  4. It comes back on the next visit
  5. Optional: allow sites for annotations

Versions 0.5 to 0.8 shipped between 8 and 13 February 2026, when the product was renamed from Notes Stack to re:note. Version 1.0 followed on 18 September 2026 and went live in the Chrome Web Store on 21 September 2026.

The extension is built with Plasmo, React, TypeScript, Tiptap, and Dexie, under strict type-checked lint rules. The site is a Next.js static export in the same monorepo.
